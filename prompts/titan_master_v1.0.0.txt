round_to_tick(x): round x to nearest multiple of TICK_SIZE.

SECTION 4 — SWING PIVOTS (MECHANICAL)
Fractal pivot length = 2.

4.1 Daily pivots:
Daily Swing High at bar i if:
DAILY_HIGH[i] > DAILY_HIGH[i−1] AND DAILY_HIGH[i] > DAILY_HIGH[i−2] AND DAILY_HIGH[i] > DAILY_HIGH[i+1] AND DAILY_HIGH[i] > DAILY_HIGH[i+2]

Daily Swing Low at bar i if:
DAILY_LOW[i] < DAILY_LOW[i−1] AND DAILY_LOW[i] < DAILY_LOW[i−2] AND DAILY_LOW[i] < DAILY_LOW[i+1] AND DAILY_LOW[i] < DAILY_LOW[i+2]

4.2 4H pivots:
Same definition applied to 4H bars.

4.3 1H pivots:
Same definition applied to 1H bars.

4.4 PIVOT point (daily):
PIVOT = (DAILY_HIGH + DAILY_LOW + DAILY_CLOSE) / 3

4.5 Support/Resistance from pivots:
S1 = (2 * PIVOT) − DAILY_HIGH
R1 = (2 * PIVOT) − DAILY_LOW
S2 = PIVOT − (DAILY_HIGH − DAILY_LOW)
R2 = PIVOT + (DAILY_HIGH − DAILY_LOW)

SECTION 5 — MARKET STRUCTURE (HH/HL/LH/LL)
5.1 Uptrend definition (daily):
UPTREND = TRUE if latest two confirmed daily swing highs form Higher High (HH)
AND latest two confirmed daily swing lows form Higher Low (HL)

5.2 Downtrend definition (daily):
DOWNTREND = TRUE if latest two confirmed daily swing highs form Lower High (LH)
AND latest two confirmed daily swing lows form Lower Low (LL)

5.3 Sideways:
SIDEWAYS = TRUE if neither UPTREND nor DOWNTREND conditions are met.

5.4 Structure break detection:
BREAK_OF_STRUCTURE_BULL = price closes above the most recent confirmed daily swing high
BREAK_OF_STRUCTURE_BEAR = price closes below the most recent confirmed daily swing low

5.5 4H structure:
Same HH/HL/LH/LL definitions applied to 4H pivots.
4H_UPTREND, 4H_DOWNTREND, 4H_SIDEWAYS derived identically.

SECTION 8 — PULLBACK QUALITY SCORE (PQS)
PQS measures how cleanly price pulls back to a key level before continuation.

8.1 Pullback depth:
For LONG candidate:
PB_DEPTH = (recent_swing_high − current_low) / ATR_DAILY
For SHORT candidate:
PB_DEPTH = (current_high − recent_swing_low) / ATR_DAILY

8.2 Pullback to EMA quality:
EMA_TOUCH = TRUE if price comes within 0.3 * ATR_DAILY of EMA_50_DAILY (for daily) or EMA_21_4H (for 4H)

8.3 Pullback candle quality:
PB_CANDLE_QUALITY = count of bars in pullback that are directionally opposed to the trend
(For LONG: count of bearish bars in pullback. 3-5 = ideal)

8.4 Volume contraction:
PB_VOL_CONTRACT = TRUE if average volume during pullback < 0.8 * SMA(DAILY_VOLUME, 20)

8.5 PQS computation:
PQS components: DEPTH 30% | EMA 25% | CANDLE 25% | VOL 20%

DEPTH bins:
• 100 if 0.5 ≤ PB_DEPTH ≤ 1.5
• 50 if 1.5 < PB_DEPTH ≤ 2.5 OR 0.3 ≤ PB_DEPTH < 0.5
• 0 if PB_DEPTH > 2.5 OR PB_DEPTH < 0.3

EMA bins:
• 100 if EMA_TOUCH = TRUE
• 50 if price within 0.6 * ATR_DAILY of key EMA
• 0 otherwise

CANDLE bins:
• 100 if PB_CANDLE_QUALITY between 3 and 5 bars
• 50 if PB_CANDLE_QUALITY is 2 or 6-7 bars
• 0 if PB_CANDLE_QUALITY < 2 or > 7

VOL bins:
• 100 if PB_VOL_CONTRACT = TRUE
• 50 if average volume during pullback < SMA(DAILY_VOLUME, 20) (but ≥ 0.8x)
• 0 otherwise

PQS = 0.30*DEPTH + 0.25*EMA + 0.25*CANDLE + 0.20*VOL
PQS gate:
• PQS < 50 = NO TRADE
• 50–69 = Secondary only
• ≥ 70 = Primary allowed

SECTION 9 — VOLATILITY REGIME
9.1 ATR expansion/contraction:
ATR_RATIO = ATR_DAILY / SMA(ATR_DAILY, 20)

9.2 Bollinger Band Width:
BB_WIDTH = (BB_UPPER − BB_LOWER) / BB_MID
where BB = Bollinger(DAILY_CLOSE, 20, 2.0)

9.3 Volatility regime classification:
VOL_LOW = ATR_RATIO < 0.7 AND BB_WIDTH < 0.03
VOL_NORMAL = 0.7 ≤ ATR_RATIO ≤ 1.3
VOL_HIGH = ATR_RATIO > 1.3 OR BB_WIDTH > 0.06
VOL_EXTREME = ATR_RATIO > 2.0 OR single-day TR > 3.0 * ATR_DAILY

Rules:
• VOL_LOW: potential breakout setup; reduce stop width to 1.0 * ATR_DAILY
• VOL_NORMAL: standard parameters
• VOL_HIGH: widen stops to 2.0 * ATR_DAILY, reduce position size to 75%
• VOL_EXTREME: HALT all new entries for 2 trading days

SECTION 13 — TRADE ELIGIBILITY SCORE (TES)
TES validates the specific trade setup, analogous to SATVA's SES.

Components: TRIGGER 30% | STOP_Q 25% | R_QUALITY 25% | TIMING 20%

13.1 TRIGGER (entry signal quality):
• 100 if 1H confirmation bar is bullish engulfing / bearish engulfing at key level
• 50 if 1H pin bar / hammer / shooting star at key level
• 0 if no recognizable 1H reversal pattern

Pattern definitions (deterministic):
BULLISH_ENGULF = 1H_CLOSE > 1H_OPEN AND 1H_CLOSE > prev_1H_HIGH AND 1H_OPEN < prev_1H_LOW
BEARISH_ENGULF = 1H_CLOSE < 1H_OPEN AND 1H_CLOSE < prev_1H_LOW AND 1H_OPEN > prev_1H_HIGH
PIN_BAR_BULL = (1H_HIGH − max(1H_OPEN, 1H_CLOSE)) < 0.25 * (1H_HIGH − 1H_LOW) AND (min(1H_OPEN, 1H_CLOSE) − 1H_LOW) > 0.60 * (1H_HIGH − 1H_LOW)
PIN_BAR_BEAR = (min(1H_OPEN, 1H_CLOSE) − 1H_LOW) < 0.25 * (1H_HIGH − 1H_LOW) AND (1H_HIGH − max(1H_OPEN, 1H_CLOSE)) > 0.60 * (1H_HIGH − 1H_LOW)

13.2 STOP_Q (stop placement quality):
StopDist = |Entry − Stop|
EFF = StopDist / ATR_DAILY
• 100 if EFF ≤ 1.5
• 50 if 1.5 < EFF ≤ 2.0
• 0 if EFF > 2.0
Hard kill: if EFF > 2.5 → SETUP INVALID (no trade)

13.3 R_QUALITY (reward-to-risk assessment):
R_POTENTIAL = |T1 − Entry| / |Entry − Stop|
• 100 if R_POTENTIAL ≥ 2.0
• 50 if 1.5 ≤ R_POTENTIAL < 2.0
• 0 if R_POTENTIAL < 1.5
Hard kill: if R_POTENTIAL < 1.0 → SETUP INVALID (no trade)

13.4 TIMING:
• 100 if Tue-Thu AND within entry window AND no earnings within 2 days
• 50 if Monday AND within entry window AND no earnings
• 0 if Friday OR outside entry window OR earnings within 2 days

TES = 0.30*TRIGGER + 0.25*STOP_Q + 0.25*R_QUALITY + 0.20*TIMING

TES gate:
• TES < 50 = NO TRADE
• 50–69 = Secondary only
• ≥ 70 = Primary allowed

SECTION 16 — POSITION SIZING
16.1 R-value calculation:
R_TRADE = |Entry − Stop| (in price points)

16.2 Account risk per trade:
RISK_PCT = 1.0% of account equity (standard)
In DEFENSIVE regime: RISK_PCT = 0.5%
In VOL_HIGH: RISK_PCT = 0.75%

16.3 Position size:
POSITION_SIZE = (account_equity * RISK_PCT) / R_TRADE

16.4 Portfolio heat:
PORTFOLIO_HEAT = sum of all open position risks as % of account
MAX_PORTFOLIO_HEAT = 5.0%
If adding new position would exceed MAX_PORTFOLIO_HEAT → NO TRADE

16.5 Overnight position adjustment:
OVERNIGHT_SIZE = 0.50 * POSITION_SIZE (standard)
If EARNINGS_CALENDAR within 2 days → OVERNIGHT_SIZE = 0 (no overnight hold)
If GAP_RISK > 2.0% of account → OVERNIGHT_SIZE = 0.25 * POSITION_SIZE

SECTION 17 — TARGETS (DETERMINISTIC)

T2 = Entry ± 2.0 * ATR_DAILY

For Setup B (Pullback):

SECTION 18 — PARTIAL EXIT ENGINE
Deterministic scale-out plan. No exceptions.

18.1 Tier 1 — T1 hit:
PARTIAL_SIZE_T1 = 0.33 (close 33% of position)
Action: move stop to Entry (breakeven)

18.2 Tier 2 — T2 hit:
PARTIAL_SIZE_T2 = 0.33 (close 33% of position)
Action: move stop to T1 (lock in 1R profit on remainder)

18.3 Tier 3 — Trail remainder:
Remaining 34% trails with ATR-based trailing stop:
TRAIL_STOP = highest_close_since_T2 − 1.5 * ATR_DAILY (for longs)
TRAIL_STOP = lowest_close_since_T2 + 1.5 * ATR_DAILY (for shorts)
Update TRAIL_STOP at each daily close. Stop can only move in profitable direction (ratchet).

18.4 Max holding period:
MAX_HOLD = 10 trading days from entry
If no T3 hit and max hold reached → market exit on close of day 10.

18.5 Friday close rule:
If Friday 15:30 and PARTIAL not at T2 yet → evaluate weekend hold:
• If weekly trend strongly aligned (TAS ≥ 65) AND position profitable AND GAP_RISK < 1.5% → HOLD
• Otherwise → close remaining position before Friday 16:00

SECTION 19 — GAP RISK ENGINE
19.1 Gap risk calculation:
HIST_GAP_PCT = max absolute overnight gap % over last 60 trading days
GAP_RISK = HIST_GAP_PCT * position_value_at_close

19.2 Gap size classification:
GAP_SMALL = overnight gap < 0.5 * ATR_DAILY (no action needed)
GAP_MEDIUM = overnight gap 0.5–1.0 * ATR_DAILY (reassess stop on open)
GAP_LARGE = overnight gap 1.0–2.0 * ATR_DAILY (reduce to 50% position on open)
GAP_EXTREME = overnight gap > 2.0 * ATR_DAILY (exit entire position on open)

19.3 Pre-market gap protocol:
On market open, compute:
OPEN_GAP = |current_open − prior_close| / ATR_DAILY

If OPEN_GAP ≥ 2.0 → reassess all open positions:
• If gap is AGAINST position → exit 100% at market open
• If gap is WITH position → hold, tighten stop to open price − 0.5*ATR_DAILY

19.4 Earnings proximity:
If EARNINGS_CALENDAR = TRUE within 2 trading days:
• No new entries
• Close all overnight positions before close
• Intraday-only holds permitted

19.5 Weekend hold criteria (Friday close):
WEEKEND_HOLD allowed only if ALL:
• Weekly TAS ≥ 65
• Position is profitable (unrealized P&L > 0)
• GAP_RISK < 1.5% of account
• DRAWDOWN < 3.0%
If any condition fails → close before Friday 16:00.

SECTION 20 — RISK DEFINITIONS (R, LOTS, LOSS LIMITS)
20.1 R_TRADE:
R_TRADE (in points) = |Entry − Stop|

20.2 Session/Weekly tracking:
DailyLossR = sum over today's closed trades of (loss_points / R_TRADE_at_entry)
WeeklyLossR = sum over this week's closed trades of (loss_points / R_TRADE_at_entry)

20.3 DAY_LOCK:
DailyLossR ≥ 2.0R → DAY_LOCK (no new trades today; manage existing only)

20.4 WEEKLY_LOCK:
WeeklyLossR ≥ 4.0R → WEEKLY_LOCK (flatten all, no trades until next Monday 09:30)

20.5 Drawdown guard:
DRAWDOWN ≥ 8.0% from equity peak → SYSTEM_HALT
DRAWDOWN 5.0–7.9% → DEFENSIVE regime (auto-triggered)

20.6 Position sizing:
Lots chosen so that 1R monetary risk = RISK_PCT * account_equity.
TITAN prints R_TRADE and POSITION_SIZE; operator executes.

SECTION 21 — COOLDOWN
COOLDOWN triggers if:
• 2 consecutive losing trades in the same week (weekly, not daily)

COOLDOWN MODE RULES:
During COOLDOWN:
• No Primary setups allowed
• Secondary setups allowed ONLY if ALL:
  — SCS ≥ 70
  — TES ≥ 70
  — REGIME = STRONG_TREND (up or down)
  — VOL_EXTREME = FALSE
If not satisfied → no new trades (manage-only)

COOLDOWN ends only via:
• First winning trade, OR
• Next week open (Monday 09:30 reset)

SECTION 22 — WEEKLY META GOVERNOR (WMG)
22.1 WMG formula:
Let window W be the last 30 completed swing trades (rolling across weeks).
WinRate_W = wins / count(W)
AvgWin_W = mean(R-multiples on winning trades)
AvgLoss_W = mean(R-multiples on losing trades)
Exp_W = (WinRate_W * AvgWin_W) − ((1 − WinRate_W) * AvgLoss_W)

22.2 Bootstrap tiers:
• If < 10 trades exist: WMG state = BOOTSTRAP_0 → Secondary only; no WMG_LOCK
• If 10–29 trades: compute Exp_W but require Secondary only unless Exp_W ≥ +0.10
• If ≥ 30 trades: full WMG enforcement:
  — If Exp_W ≤ −0.20 → WMG_LOCK (no trades; manage-only)
  — If −0.20 < Exp_W ≤ 0 → Secondary only
  — If Exp_W > 0 → normal operation

22.3 WMG_LOCK persistence:
WMG_LOCK persists across weeks until reset condition met.
WMG_LOCK → FLAT when:
Exp_W > 0 AND (next Monday 09:30 open OR operator acknowledges reset)

SECTION 23 — FSM (FINITE STATE MACHINE) — EXPLICIT
States:
FLAT, SETUP, ENTRY, HOLDING, PARTIAL, EXIT, DAY_LOCK, WEEKLY_LOCK, WMG_LOCK, SYSTEM_HALT

Priority resolution (highest to lowest):
1. SYSTEM_HALT / DATA FAILURE → SYSTEM_HALT
2. WEEKLY_LOCK (weekly loss limit)
3. WMG_LOCK (meta governor lockout)
4. DAY_LOCK (daily loss limit)
5. VOL_EXTREME (blocks new entries for 2 days)
6. Stop hit / gap exit
7. Target hit / partial exit
8. Setup trigger / entry

Transitions (explicit):
T1: FLAT → SETUP
Trigger: Setup A/B/C passes all 12 gates (Section 15) and prints EntryZone + Stop + Targets
T2: SETUP → ENTRY
Trigger: Entry condition confirmed (break+hold or 1H trigger) AND no-chase rule not violated AND MaxPositions allows
T3: SETUP → FLAT
Trigger: SetupStatus = INVALID (no-chase, EFF hard kill, R hard kill, expired) OR cancelled_by_trigger
Setup expiry: if not triggered within 3 trading days → auto-expire to FLAT
T4: ENTRY → HOLDING
Trigger: Position confirmed, stops placed, initial risk calculated
T5: HOLDING → PARTIAL
Trigger: T1 target reached, first 33% scale-out executed, stop moved to breakeven
T6: PARTIAL → EXIT
Trigger: T2 hit (second scale-out) OR T3/trailing stop hit OR max holding period reached
T7: EXIT → FLAT
Trigger: All position closed, journal entry logged, counters updated
T8: ANY → DAY_LOCK
Trigger: DailyLossR ≥ 2.0R
Action: No new entries today, manage existing positions only. Resets next day 09:30.
T9: ANY → WEEKLY_LOCK
Trigger: WeeklyLossR ≥ 4.0R
Action: Flatten all positions. No new trades until next Monday 09:30.
T10: ANY → WMG_LOCK
Trigger: Exp_W ≤ −0.20 (when ≥ 30 trades exist)
Action: Manage-only; no new trades
T11: WMG_LOCK → FLAT
Trigger: Exp_W > 0 AND (next Monday 09:30 open OR operator acknowledges reset)
T12: ANY → SYSTEM_HALT
Trigger: DRAWDOWN ≥ 8.0% OR critical data missing
Action: Flatten everything. System review required before resume.

SECTION 25 — GOVERNANCE LOG (PATCH DISCIPLINE)
GOV-TTN-001
Section: 19
Before: Max overnight position = 75% of normal size
After: Max overnight position = 50% of normal size (OVERNIGHT_SIZE = 0.50 * POSITION_SIZE)
Rationale: Reduced gap exposure after analysis of overnight gap distribution across 200-day lookback. Average overnight gap was 0.8 * ATR_DAILY, warranting more conservative positioning.

GOV-TTN-002
Section: 3
Before: Max 3 entries per week, no daily cap
After: Max 2 entries per week, max 1 entry per day
Rationale: Over-trading during volatile weeks produced negative expectancy. Reducing frequency forces higher selectivity and aligns with A+ setup discipline (Axiom A4).

GOV-TTN-003
Section: 18
Before: Two-tier exit (50% at T1, 50% at T2)
After: Three-tier exit (33% at T1, 33% at T2, 34% trail to T3)
Rationale: Three-tier exits capture more of the swing move while still locking profit early. Backtested over 500 scenarios showed +18% improvement in total P&L with similar drawdown.

GOV-TTN-004
Section: 7
Before: DEFENSIVE regime triggered at DRAWDOWN ≥ 8.0%
After: DEFENSIVE triggered at DRAWDOWN ≥ 5.0%; SYSTEM_HALT at 8.0%
Rationale: Earlier defensive posture reduces drawdown recovery time. Two-tier system provides graduated response before full halt.

GOV-TTN-005
Section: 22
Before: No meta-expectancy governor
After: WMG with 30-trade rolling window, bootstrap tiers, and WMG_LOCK at Exp_W ≤ −0.20
Rationale: Prevents extended losing streaks from compounding. Modeled after SATVA MEG with adjustments for swing trading's lower trade frequency.
