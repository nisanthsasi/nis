SECTION 2 — CORE MEASUREMENTS
2.1 TrueRange (TR) for 5m bar i:
TR[i] = max(High[i]−Low[i], abs(High[i]−Close[i−1]), abs(Low[i]−Close[i−1]))
2.2 ATR5m:
ATR5m = SMA(TR, 14) on 5m, computed on completed candles only.
2.3 ATR_prev (for contraction baseline):
ATR_prev = mean(ATR5m values over prior 24 completed 5m bars)
2.4 ATR1H:
ATR1H = SMA(TR_1H, 14) on 1H bars, computed on completed candles only.
If 1H data missing → ATR1H = undefined; TAS degraded.
2.5 EMA computations:
EMA_20_1H = EMA(1H_Close, 20)
EMA_50_1H = EMA(1H_Close, 50)
If fewer than 50 completed 1H bars → EMA_50_1H = undefined; TAS.HTF scores 0.
2.6 RSI computations:
RSI_5m = RSI(14) on completed 5m closes (Wilder smoothing)
RSI_1H = RSI(14) on completed 1H closes (Wilder smoothing)
If fewer than 14 bars available → RSI = undefined; MOM component scores 0.
2.7 SLIPPAGE model (non-circular; FIXED)
SLIPPAGE_BASE = max(1*TICK_SIZE, round_to_tick(0.02*ATR5m))
If ABT_ACTIVE = TRUE: SLIPPAGE_PAD = round_to_tick(1.5 * SLIPPAGE_BASE)
Else: SLIPPAGE_PAD = SLIPPAGE_BASE
round_to_tick(x): round x to nearest multiple of TICK_SIZE.
2.8 EfficiencyRatio (ER) — NEW IN v15.1:
ER_5m = |Close[i] − Close[i−20]| / sum(|Close[j] − Close[j−1]| for j = i−19 to i)
Range: 0.0 (pure noise) to 1.0 (perfect trend).
Used in Regime classification (Section 17) and as auxiliary trend signal.

5m Swing Low at bar i if:

SECTION 13 — MOMENTUM CONFIRMATION (MOM)
13.1 RSI Confirmation
For LONG: RSI_5m must be in range 40–70 (not overbought)
For SHORT: RSI_5m must be in range 30–60 (not oversold)
If RSI_5m = undefined → MOM_RSI = 50 (neutral).
MOM_RSI bins:
• 100 if RSI in valid range AND moving toward direction
• 50 if RSI in valid range but flat
• 0 if RSI outside valid range

13.2 Divergence Detection
BULL_DIVERGENCE = price makes Lower Low on 5m (last 40 bars) AND RSI_5m makes Higher Low over same window.
BEAR_DIVERGENCE = price makes Higher High on 5m (last 40 bars) AND RSI_5m makes Lower High over same window.
Divergence flag:
• If BULL_DIVERGENCE detected while SHORT candidate → MOM_DIV = −50 (penalize)
• If BEAR_DIVERGENCE detected while LONG candidate → MOM_DIV = −50 (penalize)
• Otherwise → MOM_DIV = 0

13.3 Order Flow Imbalance (OFI) — NEW IN v15.1
OFI = mean((Close−Low) / max(High−Low, TICK_SIZE) over last 5 completed 5m bars)
Range: 0.0 (all selling) to 1.0 (all buying).
OFI_BULL = TRUE if OFI >= 0.65 (buying pressure dominant)
OFI_BEAR = TRUE if OFI <= 0.35 (selling pressure dominant)
OFI alignment bonus:
• If LONG and OFI_BULL → MOM_OFI = +15
• If SHORT and OFI_BEAR → MOM_OFI = +15
• Otherwise → MOM_OFI = 0

13.4 MOM Computation
MOM = max(0, MOM_RSI + MOM_DIV + MOM_OFI)
MOM gate:
• MOM < 20 = NO TRADE
MOM bins (for SES):
• 100 if MOM >= 80
• 50 if 20 <= MOM < 80
• 0 if MOM < 20

14.1 Average Volume

14.2 Volume Trend Classification

VOL_CONTRACTING = TRUE if Volume_5m < 0.8 * AVG_VOL_20

14.3 Volume-Price Divergence
VP_DIV_BULL = price declining over last 6 bars AND volume declining over same (supply drying up)
VP_DIV_BEAR = price rising over last 6 bars AND volume declining over same (demand weakening)

• 0 if VOL_DRYUP = TRUE OR VP_DIV against direction

SECTION 15 — PQS (PULLBACK QUALITY SCORE)
PQS measures how cleanly price pulls back before continuation.
Only computed when a pullback is detected (Setup B/D candidates).
If no pullback context → PQS = N/A; skip PQS gate.

15.1 Pullback Depth
For LONG: PB_DEPTH = (most_recent_5m_swingHigh − current_price) / ATR5m
For SHORT: PB_DEPTH = (current_price − most_recent_5m_swingLow) / ATR5m

15.2 Pullback Candle Quality
PB_CANDLE_Q = count of bars in pullback that are directionally opposed to the trend.
For LONG pullback: count bearish bars (Close < Open).
Ideal count = 3–5 bars.

15.3 Volume Contraction During Pullback
PB_VOL_CONTRACT = TRUE if mean(Volume over pullback bars) < 0.8 * AVG_VOL_20

15.4 PQS Computation
Weights: DEPTH 40% | CANDLE 30% | VOL 30%
DEPTH bins:
• 100 if 0.5 <= PB_DEPTH <= 1.5
• 50 if 1.5 < PB_DEPTH <= 2.0 OR 0.3 <= PB_DEPTH < 0.5
• 0 if PB_DEPTH > 2.0 OR PB_DEPTH < 0.3
CANDLE bins:
• 100 if 3–5 bars
• 50 if 2 or 6–7 bars
• 0 if <2 or >7 bars
VOL bins:
• 100 if PB_VOL_CONTRACT = TRUE
• 50 if mean vol < AVG_VOL_20 but >= 0.8x
• 0 otherwise
PQS = 0.40*DEPTH + 0.30*CANDLE + 0.30*VOL

PQS gate:
• PQS < 40 = pullback setup INVALID
• 40–69 = Secondary only
• >= 70 = Primary allowed

BEH bins:

• 0 otherwise

16.4 LVL (level cleanliness)

A bar "chops through" a key level if it crosses a level in L and closes on the opposite side within the same bar.
LVL bins:
• 100 if ChopThroughCount <= 1
• 50 if ChopThroughCount <= 3
• 0 otherwise

16.5 VOLP (Volume Profile Quality)

16.6 TIME bins:

16.7 RCS computation:
RCS = 0.15*TAS + 0.10*VOL + 0.15*BEH + 0.25*LVL + 0.15*VOLP + 0.20*TIME
RCS gate:

SECTION 17 — REGIME BANNER (PRINT ALWAYS)
Regime is derived deterministically using a hybrid detector:
Primary: Rule-based (same structure as v15.0.0)
Auxiliary: EfficiencyRatio confirmation (new in v15.1)

ER_regime:
• ER_5m >= 0.40 → ER_TRENDING
• 0.20 <= ER_5m < 0.40 → ER_MIXED
• ER_5m < 0.20 → ER_CHOPPY

Regime rules:
If ABT_ACTIVE = TRUE → REGIME = SHOCK
Else if RCS.VOL = 0 AND ER_5m < 0.20 → REGIME = SHOCK (both must agree)
Else if CompressionValid = TRUE AND ExpansionValid = FALSE AND EntropyScore <= 40 AND ER_5m < 0.30 → REGIME = RANGE
Else if ExpansionStrong = TRUE AND TAS >= 60 AND EntropyScore <= 40 AND RCS >= 70 AND ER_5m >= 0.40 → REGIME = STRONG_TREND
Else if ExpansionValid = TRUE AND EntropyScore <= 40 AND RCS >= 65 → REGIME = TREND
Else if EntropyScore 41–54 OR RCS 65–69 → REGIME = UNCLEAR
Else → REGIME = UNCLEAR
(UNCLEAR = Secondary only; SHOCK = manage-only)

Regime smoothing: A regime change requires 3 consecutive bars of the new regime signal before switching. This prevents rapid flipping.

Close_hold >= Level  (for long)

Setup D — MOMENTUM PULLBACK (TREND or STRONG_TREND)
Eligibility:
REGIME = TREND or STRONG_TREND, RCS >= 70, SES >= 70, PQS >= 40, ABT_ACTIVE=FALSE, TAS >= 20, MOM >= 20.

SECTION 22 — PARTIAL EXIT ENGINE (3-TIER, REGIME-ADAPTIVE)
Default exit structure:

Tier 1: T1 hit → Close 40% of position → Move stop to Entry + 0.10*ATR5m (breakeven pad)
Tier 2: T2 hit → Close 30% of position → Move stop to T1 (lock partial profit)
Tier 3: Remaining 30% trails with ATR-based trailing stop (ratchet):
TRAIL_STOP (LONG) = highest_close_since_T2 − 1.0*ATR5m
TRAIL_STOP (SHORT) = lowest_close_since_T2 + 1.0*ATR5m
Update TRAIL_STOP at each completed 5m bar close. Stop can only move in profitable direction (ratchet).

Runner kill conditions (REGIME-ADAPTIVE):
• STRONG_TREND: kill runner if giveback >= 0.50*ATR5m from peak_after_T2
• TREND: kill runner if giveback >= 0.15*ATR5m from peak_after_T2
• RANGE: kill runner if giveback >= 0.40*ATR5m from peak_after_T2
• UNCLEAR: kill runner if giveback >= 0.15*ATR5m from peak_after_T2
• If REGIME transitions to SHOCK while runner active → auto-kill runner at next bar close

Setup C exception: two-tier split only — close half at T1, close remainder at T2 (no runner; range trades capped).
Time-based runner kill: if runner still active with < 30 minutes to SESSION_CLOSE → exit at market.

SECTION 23 — TIME STOPS (INTRADAY)
23.1 Setup expiry:
If an ARMED setup does not trigger within 6 completed 5m bars (30 minutes) → ARMED→FLAT (reason=TIME_EXPIRED).
23.2 Max hold period:
If IN_POSITION for more than 120 completed 5m bars (10 hours) → exit at market on next bar close.
23.3 End-of-session rule:
At 23:00 IST (30 min before close): if IN_POSITION → begin exit sequence:
• If at profit >= 0.5R → exit at market
• If at loss → hold until stop or 23:25 IST, then exit at market
No positions held overnight. All positions must be flat by 23:30 IST.

SECTION 24 — POSITION SIZING (REGIME-ADAPTIVE)
24.1 R-value calculation:
R_trade (in points) = |Entry − Stop|
24.2 Account risk per trade:
Standard RISK_PCT by regime:
• STRONG_TREND: RISK_PCT = 1.25% of session capital
• TREND: RISK_PCT = 1.0% of session capital
• RANGE: RISK_PCT = 0.75% of session capital
• UNCLEAR: RISK_PCT = 0.50% of session capital
If COOLDOWN active: RISK_PCT = 0.5% regardless of regime
If session has 1 prior loss (TradeCount_Losses >= 1): reduce RISK_PCT by 25%
24.3 Position size formula:
POSITION_SIZE = (session_capital * RISK_PCT) / R_trade
SATVA prints R_trade and POSITION_SIZE; operator executes.
24.4 Portfolio heat:
PORTFOLIO_HEAT = sum of all open position risks as % of session capital
MAX_PORTFOLIO_HEAT = 3.0%
If adding new position would exceed MAX_PORTFOLIO_HEAT → NO TRADE.

SECTION 25 — RISK DEFINITIONS (R, LOTS, LOSS LIMITS)
R_trade (in points) = |Entry − Stop|
SessionLossR = sum over closed trades of (loss_points / R_trade_at_entry)
SESSION_LOCK triggers when SessionLossR >= 1.75
Drawdown guard triggers when unrealized + realized < −2.5R
Position sizing:
Lots must be selected so that 1R monetary risk fits operator's risk budget.
SATVA prints R_trade; operator chooses lots.

SECTION 26 — DATA HEALTH & WATCHDOGS
26.1 Data freshness watchdog:
If last received 5m bar timestamp is > 10 minutes stale → DATA_STALE warning.
If stale > 20 minutes → SESSION_LOCK (data feed assumed dead).
26.2 Volume anomaly watchdog:
If Volume = 0 for 3 consecutive 5m bars → DATA_SUSPECT warning (possible feed issue).
26.3 Price gap watchdog:
If |current_bar_open − previous_bar_close| > 1.5*ATR5m → PRICE_GAP_ALERT (log only; does not halt).
26.4 Health status output:
DataHealth = OK | STALE | SUSPECT | HALT
Print DataHealth in every output block.

SECTION 27 — COOLDOWN
COOLDOWN triggers if:
• 3 consecutive losing trades in the same session (filled trades)
COOLDOWN MODE RULE:
During COOLDOWN:
• No Primary setups allowed
• Position size reduced to 50% (RISK_PCT = 0.5%)
• Secondary setups allowed ONLY if ALL:
– RCS >= 75
– SES >= 80
– EntropyScore <= 40
– ABT_ACTIVE = FALSE
– MOM >= 50
If not satisfied → no new trades (manage-only)
COOLDOWN ends only via:
• first winning trade, OR
• next session open (09:00 reset)

SECTION 28 — MEG (META EXPECTANCY GOVERNOR) + BOOTSTRAP
Exp_M formula:
Let window W be last 30 filled trades (rolling across sessions).
WinRate = wins/W_count
LossRate = 1 − WinRate
AvgWin = mean(points gained on winning trades)
AvgLoss = mean(points lost on losing trades)
Exp_M = (WinRate*AvgWin) − (LossRate*AvgLoss)
Bootstrap tiers:
• If < 15 trades exist: MEG state = BOOTSTRAP_0 → Secondary only; no MEG_LOCK
• If 15–29 trades: compute Exp_M but require Secondary only unless Exp_M >= +0.01
• If >= 30 trades: full MEG enforcement:
– If Exp_M <= −0.05 → MEG_LOCK (no trades; manage-only)
– If −0.05 < Exp_M <= 0 → Secondary only
– If Exp_M > 0 → normal operation (subject to RCS/SES gates)
MEG_LOCK persistence:
MEG_LOCK persists across sessions until reset condition met.
MEG_LOCK reset:
MEG_LOCK → FLAT when:
Exp_M > 0 AND (next session open OR operator acknowledges reset)

Edge verification (continuous):
Every 15 filled trades, recompute Exp_M. If Exp_M crosses from positive to negative → print EDGE_DEGRADATION_WARNING.
If Exp_M has been negative for 3 consecutive 15-trade windows → MEG_LOCK regardless of absolute value.

SECTION 29 — FSM (FINITE STATE MACHINE) — EXPLICIT
States:
FLAT, ARMED, IN_POSITION, COOLDOWN, SESSION_LOCK, MEG_LOCK
Priority resolution (highest to lowest):
1. SYSTEM HALT / DATA FAILURE → SESSION_LOCK
2. SESSION_LOCK (loss limit or feed halt)
3. MEG_LOCK
4. ABT_ACTIVE (blocks new trades; manage-only)
5. Stop hit
6. T1/T2/T3 hit (partial exit)
7. Setup trigger / entry
Transitions (explicit):
T1: FLAT → ARMED
Trigger: A setup passes eligibility gates and prints EntryZone + Stop + T1/T2/T3
T2: ARMED → IN_POSITION
Trigger: Entry condition hits AND no-chase rule not violated AND MaxPositions allows
T3: ARMED → FLAT
Trigger: SetupStatus = INVALID (no-chase or Eff>1.8 or TIME_EXPIRED) OR operator cancels OR cancelled_by_trigger
Time expiry rule:
If setup does not trigger within 6 completed 5m candles from ARMED → expire to FLAT.
T4: IN_POSITION → FLAT
Trigger: Full exit (all tiers closed) OR time stop (max hold) OR end-of-session exit
T5: IN_POSITION → SESSION_LOCK
Trigger: SessionLossR >= 1.75 OR critical data missing OR drawdown guard triggered
Action: Flatten all open positions including runners. No exceptions.
T6: ANY → MEG_LOCK
Trigger: Exp_M <= −0.05 (when >= 30 trades exist) OR 3-window negative streak
Action: manage-only; no new trades
T7: MEG_LOCK → FLAT
Trigger: Exp_M > 0 AND (next session open OR operator acknowledges reset)
T8: ANY → COOLDOWN
Trigger: 3 consecutive losing trades in same session
T9: COOLDOWN → ARMED
Trigger: COOLDOWN MODE RULE passes AND setup signal valid
T10: COOLDOWN → FLAT
Trigger: first winning trade OR next session open
