SECTION 2 — CORE MEASUREMENTS
2.1 TrueRange (TR) for 5m bar i:
TR[i] = max(High[i]−Low[i], abs(High[i]−Close[i−1]), abs(Low[i]−Close[i−1]))
2.2 ATR5m:
ATR5m = SMA(TR, 14) on 5m, computed on completed candles only.
2.3 ATR_prev (for contraction baseline):
ATR_prev = mean(ATR5m values over prior 24 completed 5m bars)
2.4 SLIPPAGE model (non-circular; FIXED)
SLIPPAGE_BASE = max(1*TICK_SIZE, round_to_tick(0.02*ATR5m))
If ABT_ACTIVE = TRUE: SLIPPAGE_PAD = round_to_tick(1.5 * SLIPPAGE_BASE)
Else: SLIPPAGE_PAD = SLIPPAGE_BASE
round_to_tick(x): round x to nearest multiple of TICK_SIZE.

Fractal pivot length = 2.
5m Swing High at bar i if:
High[i] > High[i−1], High[i−2], High[i+1], High[i+2]
5m Swing Low at bar i if:
Low[i] < Low[i−1], Low[i−2], Low[i+1], Low[i+2]
Same definition applies to 1H pivots on 1H bars.

SECTION 8 — COMPRESSION ENGINE (5m, FIXED WINDOW)
Window N = 12 bars (last 12 completed 5m candles)
8.1 OverlapRange:
OverlapRange = min(High over N) − max(Low over N)
If OverlapRange <= 0 → OverlapRange = 0
8.2 MedianRange:
MedianRange = median(High−Low over N)
8.3 Overlap%:
OverlapPct = OverlapRange / MedianRange   (if MedianRange=0 → 0)
8.4 Contraction:
Contraction = ATR5m / ATR_prev
8.5 VolumeSlope:
VolumeSlope = linear_regression_slope(Volume over N bars)
(Use standard least squares slope; sign matters.)
CompressionValid if ALL:
• OverlapPct ≥ 0.60
• Contraction ≤ 0.85
• VolumeSlope ≤ 0
SECTION 9 — EXPANSION CLASSIFIER (VALID vs STRONG)
Compute avgBody10 = mean(|Close−Open| over last 10 completed 5m bars)
ExpansionValid if:
• TR ≥ 1.2*ATR5m  OR  Volume ≥ SMA(Volume,20)
AND
• |Close−Open| ≥ 1.2*avgBody10
ExpansionStrong if:
• TR ≥ 1.4*ATR5m  OR  Volume ≥ 1.4*SMA(Volume,20)
AND
• |Close−Open| ≥ 1.4*avgBody10
SECTION 10 — ENTROPY (INDECISION SCORE)
Define indecision candle (5m):
Indecision = 1 if any of:
• |Close−Open| ≤ 0.25*(High−Low)
• Inside bar: High ≤ prevHigh AND Low ≥ prevLow
• Doji-like: |Close−Open| ≤ 0.15*ATR5m
EntropyWindow = last 20 completed 5m bars
EntropyScore = 100 * (sum(Indecision over window) / 20)
Entropy bins:
• 0–40 = GOOD
• 41–59 = CAUTION (Secondary only)
• ≥60 = BLOCK (no trades)
SECTION 11 — VOL DEFINITIONS (ORTHOGONAL)
11.1 RCS.VOL = Environmental stability (market state)
ATR5m_series = ATR5m values for last 20 completed bars
Exclude bars where TR ≥ 2.2*ATR5m (spike exclusion)
VStab = stdev(ATR5m_series_clean) / mean(ATR5m_series_clean)
PullbackDepth (directional):
For LONG candidate: PullbackDepth = (most_recent_confirmed_swingHigh_5m − current_price) if current below that swingHigh else 0
For SHORT candidate: PullbackDepth = (current_price − most_recent_confirmed_swingLow_5m) if current above that swingLow else 0
PullbackNorm = PullbackDepth / ATR5m
RCS.VOL bins:
• 100 if VStab ≤ 0.12 AND PullbackNorm ≤ 1.0
• 50 if VStab ≤ 0.20 AND PullbackNorm ≤ 1.3
• 0 otherwise
11.2 PCO.VOL / EFF = Trade efficiency (position design)
StopDist = |Entry − Stop|
Eff = StopDist / ATR5m
Bins:
• 100 if Eff ≤ 1.0
• 50 if 1.0 < Eff ≤ 1.3
• 0 if Eff > 1.3
Hard kill: if Eff > 1.8 → SETUP INVALID (no trade)
SECTION 12 — RCS (REGIME CONFIDENCE SCORE)
RCS components scored {100,50,0} then weighted.
Weights:
HTF 30% | VOL 20% | BEH 20% | LVL 15% | TIME 15%
12.1 HTF (1H trend alignment)
If 1H data missing → HTF = 0 and Setup A disabled.
SlopeProxy_1H preferred:
Slope = SMA(Close,20) − SMA(Close,50) on 1H if ≥50 bars
Fallback 1: SMA20 − SMA40 if 40–49 bars
Fallback 2: SMA20 − SMA30 if 30–39 bars
If <30 bars → HTF=0 and Setup A disabled
HTF bins (directional, computed separately for LONG and SHORT candidates):
• 100 if Slope aligns with direction AND last close is on same side of VWAP as direction
• 50 if only one of the two is true
• 0 otherwise
12.2 BEH (behavioral clarity; candle body dominance)
BodyRatio = mean( |Close−Open| / max(High−Low, TICK_SIZE) over last 10 completed 5m bars)
BEH bins:
• 100 if BodyRatio ≥ 0.55
• 50 if 0.45 ≤ BodyRatio < 0.55
• 0 otherwise
12.3 LVL (level cleanliness)
Compute ChopThroughCount over last 24 completed 5m bars:
A bar "chops through" a key level if it crosses a level in L and closes on the opposite side within the same bar.
LVL bins:
• 100 if ChopThroughCount ≤ 1
• 50 if ChopThroughCount ≤ 3
• 0 otherwise
12.4 TIME bins:
• 100 if 09:20–20:30
• 50 if 20:30–22:30
• 0 otherwise (no new trades)
12.5 RCS computation:
RCS = 0.30*HTF + 0.20*VOL + 0.20*BEH + 0.15*LVL + 0.15*TIME
RCS gate:
• RCS < 65 = NO TRADE
• 65–69 = Secondary only
• ≥70 = Full operation

Regime is derived deterministically:

Else if CompressionValid = TRUE AND ExpansionValid = FALSE → REGIME = RANGE
Else if ExpansionValid = TRUE AND EntropyScore ≤ 40 AND RCS ≥ 70 → REGIME = TREND
Else if EntropyScore 41–59 OR RCS 65–69 → REGIME = UNCLEAR

SECTION 14 — DUAL VIOLATION (USED IN STR)

Price closed above the most recent confirmed 5m SwingHigh

SECTION 15 — SES (SETUP ELIGIBILITY SCORE)
SES components: TRIG 30% | STR 25% | LVLQ 25% | EFF 20%
15.1 TRIG (trigger quality)
• 100 if ExpansionStrong = TRUE
• 50 if ExpansionValid = TRUE (and not Strong)
• 0 otherwise
15.2 STR (structure quality; direction-symmetric)
Define confirmations using confirmed 5m pivots:
For LONG:
HH_confirmed = most recent confirmed SwingHigh > prior confirmed SwingHigh
HL_confirmed = most recent confirmed SwingLow > prior confirmed SwingLow
For SHORT:
LL_confirmed = most recent confirmed SwingLow < prior confirmed SwingLow
LH_confirmed = most recent confirmed SwingHigh < prior confirmed SwingHigh
STR bins:
• 100 if (LONG: HH_confirmed AND HL_confirmed) OR (SHORT: LL_confirmed AND LH_confirmed) AND DualViolation=FALSE
• 50 if DualViolation=FALSE AND exactly one confirmation is true:
– LONG: (HH_confirmed XOR HL_confirmed)=TRUE
– SHORT: (LL_confirmed XOR LH_confirmed)=TRUE
• 0 if DualViolation=TRUE
15.3 LVLQ (level proximity quality)
Distance = |Entry − NearestLevel(Entry)|
• 100 if Distance ≤ 0.25*ATR5m
• 50 if Distance ≤ 0.50*ATR5m
• 0 otherwise
15.4 EFF (stop efficiency)
Use Eff bins from Section 11.2.
15.5 SES computation:
SES = 0.30*TRIG + 0.25*STR + 0.25*LVLQ + 0.20*EFF
SES gate:
• SES < 65 = NO TRADE
• 65–79 = Secondary only
• ≥80 = Primary allowed
Entropy coupling:
• If EntropyScore 41–59 → Secondary only even if SES ≥80
• If EntropyScore ≥60 → Block all trades

SECTION 18 — DTE (DETERMINISTIC TRAIL EXTENSION, OPTIONAL RUNNER)
Default rule: exit 100% at T1 unless DTE is explicitly authorized.
DTE allowed only if ALL:
• REGIME = TREND
• SES ≥ 80 and RCS ≥ 70 at entry
• After T1 hit: within next 3 completed 5m candles:
PostT1Advance = (max favorable price after T1 over next 3 candles) − T1_price (long)
(or T1_price − min favorable price for short)
Requirement: PostT1Advance ≥ 0.6*ATR5m
• VWAP hold: next 3 closes remain on trend side of VWAP:
– LONG: Close >= VWAP_session
– SHORT: Close <= VWAP_session
• Giveback ≤ 0.5 ATR:
Giveback = (peak_after_T1 − last_close)/ATR5m (long) or (last_close − trough_after_T1)/ATR5m (short)
Requirement: Giveback ≤ 0.5
If DTE authorized:
• Scale out: 70% at T1, 30% runner
Runner stop:
• Move stop to Entry ± 0.10*ATR5m (breakeven pad) after T1.
Giveback kill:
• TREND: kill runner if giveback ≥ 0.35 of PostT1Advance
• RANGE: kill runner if giveback ≥ 0.20 of PostT1Advance
• SHOCK: if REGIME transitions to SHOCK while runner active → auto-kill runner at next bar close

SECTION 21 — MEG (META EXPECTANCY GOVERNOR) + BOOTSTRAP
Exp_M formula:
Let window W be last 60 filled trades (rolling across sessions).
WinRate = wins/W_count
LossRate = 1 − WinRate
AvgWin = mean(points gained on winning trades)
AvgLoss = mean(points lost on losing trades)
Exp_M = (WinRate*AvgWin) − (LossRate*AvgLoss)
Bootstrap tiers:
• If < 20 trades exist: MEG state = BOOTSTRAP_0 → Secondary only; no MEG_LOCK
• If 20–59 trades: compute Exp_M but require Secondary only unless Exp_M ≥ +0.01
• If ≥ 60 trades: full MEG enforcement:
– If Exp_M ≤ −0.15 → MEG_LOCK (no trades; manage-only)
– If −0.15 < Exp_M ≤ 0 → Secondary only
– If Exp_M > 0 → normal operation (subject to RCS/SES gates)
MEG_LOCK persistence:
MEG_LOCK persists across sessions until reset condition met.
MEG_LOCK reset (PATCH 14.4.1 — CLOSED, no ambiguity):
MEG_LOCK → FLAT when:
Exp_M > 0 AND (next session open OR operator acknowledges reset)

SECTION 24 — GOVERNANCE LOG (PATCH DISCIPLINE)
GOV-LSEC-REMOVAL-01 (documented per 14.4.1):
Change: LSEC module removed (adaptive SES threshold calibration).
Reason: Freeze deterministic controlled testing; avoid unvalidated adaptive behavior pre-data.
Replacement stability controls: COOLDOWN elevated gates + MEG governor + Entropy + ABT + strict no-chase.
Reintroduction condition: after ≥60 controlled-test trades with logged expansion outcomes; panel review required.
GOV-BEH-REVISION-02
Section: 12.2 (BEH)
Before: BEH computed via impulse/chop candle counting over a fixed window with threshold-based scoring (impulse/chop counts driving {100,50,0}).
After: BEH = BodyRatio = mean(|Close−Open| / max(High−Low, TICK_SIZE) over last 10 completed 5m bars); bins: 100 if ≥0.55, 50 if 0.45–0.55, else 0.
Rationale: Reduce fragility and subjective classification; improve robustness under small sample sizes; maintain deterministic execution with simpler continuous statistic.
GOV-LVL-REVISION-03
Section: 12.3 (LVL)
Before: LVL scored via multi-event "respect" and "chop" event counts around levels over a rolling window (approach/close-away logic).
After: LVL scored via ChopThroughCount over last 24 completed 5m bars: bar crosses a level in L and closes on opposite side within same bar; bins: 100 if ≤1, 50 if ≤3, else 0.
Rationale: Simplify and harden level quality scoring; remove approach-distance sensitivity; preserve level-cleanliness intent using a more direct deterministic definition.
GOV-ENTROPY-REVISION-04
Section: 10 (Entropy)
Before: Indecision candle used a different threshold basis (e.g., body vs median body reference and wick-ratio criterion), plus inside-bar inclusion.
After: Indecision = 1 if any of: |Close−Open| ≤ 0.25*(High−Low) OR inside bar OR |Close−Open| ≤ 0.15*ATR5m; EntropyScore = 100*(count/20) over last 20 bars; bins unchanged in spirit (GOOD/CAUTION/BLOCK).
Rationale: Anchor indecision to candle-internal structure and ATR normalization; reduce dependence on median-body estimator; maintain deterministic gating with clearer mechanical thresholds.
GOV-SES-THRESHOLD-05
Section: 15.5 (SES gate)
Before: SES had multi-tier gate including Break+Hold tier and lower Secondary floor (e.g., ≥75 Break+Hold, ≥65 Primary, 55–64 Secondary, <55 none).
After: SES gate is: <65 NO TRADE; 65–79 Secondary only; ≥80 Primary allowed; Entropy coupling preserved (41–59 forces Secondary; ≥60 blocks).
Rationale: Align operator execution with fewer discrete regimes; increase Primary conviction threshold; remove intermediate tier complexity while preserving deterministic restriction hierarchy.
GOV-REGIME-REVISION-06
Section: 13 (Regime Banner)
Before: TREND/RANGE classification required different condition set emphasizing HTF=100 and additional constraints; RANGE and TREND were more HTF-dependent in eligibility logic.
After: Regime derived as written: SHOCK if ABT_ACTIVE or RCS.VOL=0; RANGE if CompressionValid and not ExpansionValid; TREND if ExpansionValid and EntropyScore ≤40 and RCS ≥70; else UNCLEAR if Entropy 41–59 or RCS 65–69.
Rationale: Make regime classification directly reflect intraday expansion/compression + entropy + confidence; reduce hidden dependence on HTF while keeping HTF weight inside RCS.
GOV-SESSION-HOURS-07
Section: 3.4 (New trade cutoffs)
Before: No new trades after 21:45; manage-only after 22:30 (two-step cutoff).
After: New trades allowed 09:20–22:30; after 22:30 manage-only.
Rationale: Remove ambiguous intermediate window; align trading window with standardized late-session liquidity for instruments traded; keep deterministic single cutoff while preserving manage-only final phase.
GOV-DTE-REFERENCE-08
Section: 18 (DTE giveback kill reference)
Before: Giveback kill thresholds referenced ImpulseLen where ImpulseLen = |T1 − Entry|.
After: Giveback kill thresholds reference PostT1Advance (measured over next 3 candles after T1 hit), with kills at 0.35 (TREND) and 0.20 (RANGE), plus SHOCK runner auto-kill rule.
Rationale: Tie runner protection to realized extension after T1 rather than static initial impulse; reduce overexposure when extension is shallow; standardize deterministic runner behavior across regimes.
GOV-CRITICAL-PATH-09
Section: 1 (Critical-path inputs)
Before: PD reference levels were classified as non-critical under degraded operation, with reduced feature set.
After: PD levels (PDO/PDH/PDL/PDC) explicitly classified as CRITICAL-PATH; missing → SESSION_LOCK / HALT.
